style.css

공통 스타일 — 모든 페이지에 적용

nav, footer, 배경 등 어느 페이지에서나 동일하게 보여야 하는 요소들을 담당한다. 모든 HTML 파일에서 <link rel="stylesheet" href="style.css">로 불러온다.

01

기본 초기화

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

html {
  scroll-behavior: smooth;
}

body {
  margin: 0;
  padding-top: 56px;
  background-color: #0f1115;
}
* { margin: 0; padding: 0 }

브라우저마다 기본으로 붙어있는 여백을 전부 제거한다. 예를 들어 h1, p 태그는 기본 위아래 여백이 있는데 이걸 없애서 레이아웃을 직접 제어할 수 있게 한다.

box-sizing: border-box

요소 크기 계산 방식을 변경한다. 기본값(content-box)은 padding과 border를 크기에 추가하지만, border-box는 크기 안에 포함시킨다. width: 100px에 padding: 10px이면 기본값은 실제로 120px이 되는데 border-box는 그냥 100px을 유지한다.

scroll-behavior: smooth

페이지 내 앵커 링크(#섹션) 클릭 시 순간이동이 아니라 부드럽게 스크롤된다.

body { padding-top: 56px }

nav가 position: fixed라서 화면 위에 떠있다. 이 때문에 콘텐츠가 nav 뒤로 숨는 문제가 생기는데, nav 높이(56px)만큼 위쪽 패딩을 줘서 콘텐츠가 nav 아래에서 시작하게 한다.

02

배경 블러 오버레이

.page-bg::before {
  content: "";
  position: fixed;
  inset: 0;

  background:
    linear-gradient(
      to bottom,
      rgba(0,0,0,0.15) 0%,
      rgba(0,0,0,0.35) 45%,
      rgba(15,17,21,0.8) 80%,
      #0f1115 100%
    ),
    url("그냥이렐리아.jpg");

  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;

  filter: blur(3px);
  z-index: -2;
}
::before 가상 요소

실제 HTML 태그 없이 CSS만으로 요소를 생성한다. content: ""는 내용은 비우되 요소 자체는 존재하게 한다. 없으면 렌더링이 안 된다.

position: fixed / inset: 0

스크롤해도 배경이 움직이지 않고 고정된다. inset: 0은 top/right/bottom/left를 모두 0으로 설정하는 단축 표현으로 화면 전체를 꽉 채운다.

linear-gradient + url() 중첩

배경을 두 겹으로 쌓는다. 위에는 그라데이션(어두워지는 효과), 아래는 실제 이미지. 그라데이션이 이미지 위에 덮여서 텍스트가 잘 보이게 한다. 0% → 45% → 80% → 100% 순서로 점점 어두워지고 마지막은 배경색과 동일해져서 자연스럽게 사라진다.

background-size: cover

이미지 비율을 유지하면서 화면을 꽉 채우도록 자동으로 확대/축소한다. 이미지가 화면보다 작으면 잘리더라도 빈 공간 없이 채운다.

filter: blur(3px)

배경 이미지를 3px 흐리게 만든다. 전경 콘텐츠가 더 선명하게 보이는 깊이감 효과를 준다.

z-index: -2

모든 콘텐츠 뒤에 배치한다. nav는 z-index: 100, footer는 50, 콘텐츠는 기본값(0), 배경은 -2 순서다.

03

네비게이션

nav {
  position: fixed;
  top: 0; left: 0; right: 0;
  z-index: 100;
  height: 56px;
  background: #0f1115;
  border-bottom: 1px solid #c9a84c;
  display: flex;
  align-items: center;
  padding: 0 32px;
}

.nav-inner {
  width: 100%;
  display: flex;
  align-items: center;
}

.nav-logo {
  margin-right: auto;
  /* 나머지 폰트/색상 생략 */
}

.nav-links a {
  color: #888;
  border-left: 1px solid #222;
  transition: color 0.2s, background 0.2s;
}

.nav-links a:hover {
  color: #c9a84c;
  background: rgba(201,168,76,0.08);
}

.nav-links a.active {
  color: #c9a84c;
}
position: fixed + top/left/right: 0

스크롤해도 항상 화면 상단에 고정된다. top/left/right를 모두 0으로 해서 화면 전체 너비를 차지한다.

z-index: 100

가장 높은 z-index값이라 배경(-2), 콘텐츠(0), 푸터(50) 모두 nav 뒤에 배치된다. 어떤 요소도 nav를 가리지 못한다.

.nav-logo { margin-right: auto }

flex 컨테이너에서 margin: auto는 남은 공간을 전부 해당 방향으로 밀어낸다. margin-right: auto이면 로고 오른쪽 공간이 최대로 벌어져서 로고는 왼쪽 끝, 나머지 요소는 오른쪽 끝으로 붙는다.

border-left: 1px solid #222

링크 사이 구분선이다. 첫 번째 링크는 :first-child로 border-left를 none 처리해서 왼쪽 끝 선을 제거한다.

transition: color 0.2s, background 0.2s

호버 시 색상과 배경이 0.2초에 걸쳐 부드럽게 전환된다. 없으면 즉각적으로 바뀌어서 딱딱한 느낌이 난다.

.active 클래스

JS나 HTML에서 현재 페이지 링크에 class="active"를 붙이면 골드색으로 강조된다. 지금 어느 페이지에 있는지 시각적으로 알려준다.

04

푸터 (고정 + 그라데이션)

footer {
  position: fixed;
  bottom: 0;
  left: 0; right: 0;
  z-index: 50;
  background: transparent;
}

footer::before {
  content: "";
  position: fixed;
  bottom: 0;
  left: 0; right: 0;
  height: 120px;
  z-index: -1;
  background: linear-gradient(
    to bottom,
    rgba(15,17,21,0) 0%,
    rgba(15,17,21,0.85) 85%,
    #0f1115 100%
  );
  pointer-events: none;
}
position: fixed + bottom: 0

스크롤과 상관없이 화면 하단에 항상 고정된다. z-index: 50으로 콘텐츠 위에 뜨되 nav(100)보다는 아래에 위치한다.

background: transparent

푸터 자체는 투명하게 해서 아래의 그라데이션(::before)이 그대로 보인다.

footer::before — 그라데이션 오버레이

120px 높이의 그라데이션을 생성한다. 위쪽은 완전 투명(rgba 0) → 아래쪽은 배경색과 동일(#0f1115)로 바뀌면서 콘텐츠가 자연스럽게 페이드아웃되는 효과를 준다.

pointer-events: none

그라데이션 오버레이가 마우스 클릭을 가로막지 않게 한다. 없으면 그라데이션 영역의 링크나 버튼이 클릭이 안 된다.

z-index: -1

푸터 텍스트(부모의 z-index 50 기준) 뒤에 위치하되 페이지 콘텐츠 앞에 있어서 그라데이션이 콘텐츠를 덮는다.

05

스킨 페이지

.skin-wrap {
  width: 90%;
  max-width: 1000px;
  margin: 50px auto;
  text-align: center;
}

#skin-img {
  width: 100%;
  display: block;
  transition: opacity 0.3s ease;
}
width: 90% + max-width: 1000px

화면 너비의 90%를 차지하되 최대 1000px을 넘지 않는다. 작은 화면에서는 양쪽에 5%씩 여백이 생기고, 큰 화면에서는 1000px로 고정된다.

margin: 50px auto

위아래 50px 여백, 좌우 auto로 가운데 정렬한다. block 요소에서 margin: 0 auto가 가운데 정렬의 기본 패턴이다.

display: block

img 태그의 기본값은 inline인데 inline이면 아래쪽에 글자 기준선(baseline) 공간이 생겨서 이미지 아래 여백이 생긴다. block으로 바꾸면 이 여백이 사라진다.

transition: opacity 0.3s ease

JS 슬라이더에서 이미지를 바꿀 때 opacity를 0 → 1로 조작하면 0.3초 페이드 효과가 자동으로 적용된다.

skill.html 내부 <style>

스킬 페이지 전용 스타일

skill.html의 <head> 안 <style> 태그에 작성된다. 이 페이지에서만 쓰이는 탭, 스킬 섹션, 팁/콤보 박스를 담당한다.

01

스킬 섹션 표시/숨김

.skill-sec {
  display: none !important;
}

.skill-sec.active {
  display: flex !important;
}
display: none

요소를 화면에서 완전히 숨긴다. visibility: hidden과 달리 공간 자체가 사라진다. P/Q/W/E/R 섹션이 기본적으로 전부 숨겨져 있다.

.skill-sec.active { display: flex }

JS에서 클릭한 탭에 해당하는 섹션에 active 클래스를 추가하면 display: flex가 적용되어 보인다. flex로 설정한 이유는 내부 이미지+텍스트를 가로 배치하기 위해서다.

!important

CSS 우선순위를 강제로 최상위로 올린다. style.css나 다른 스타일이 충돌해서 섹션이 전부 보이는 문제가 있었는데, !important로 덮어씌워서 해결했다.

02

페이지 타이틀

main {
  max-width: 1000px;
  margin: 0 auto;
  padding: 48px 24px 80px;
}

main h1 {
  font-size: 28px;
  font-weight: 900;
  letter-spacing: 0.15em;
  text-transform: uppercase;
  color: #c9a84c;
}

main > div > p {
  font-size: 13px;
  color: #666;
  margin-top: 8px;
}
padding: 48px 24px 80px

위 48px / 좌우 24px / 아래 80px. 아래쪽을 80px로 넉넉히 준 이유는 고정 푸터가 콘텐츠를 가리지 않게 하기 위해서다.

main > div > p

> 기호는 직계 자식만 선택한다. main 바로 아래 div, 그 바로 아래 p만 선택하는 것으로 제목 영역의 안내 문구("P / Q / W / E / R 버튼을 눌러...")에만 스타일이 적용된다. 다른 곳의 p 태그에는 영향을 주지 않는다.

03

탭 버튼

.tab-wrap {
  display: flex;
  justify-content: center;
  gap: 12px;
  margin-bottom: 40px;
}

.tab-btn {
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 6px;
  min-width: 90px;
  background: #1a1a1a;
  border: 1px solid #2a2a2a;
  border-radius: 8px;
  transition: all 0.2s;
}

.tab-btn:hover {
  border-color: #c9a84c;
  background: rgba(201,168,76,0.08);
}

.tab-btn.active {
  border-color: #c9a84c;
  background: rgba(201,168,76,0.12);
}
.tab-wrap { justify-content: center }

flex 컨테이너 안에서 자식 요소들을 가로 중앙 정렬한다. gap: 12px로 버튼 사이 간격을 일정하게 유지한다.

.tab-btn { flex-direction: column }

버튼 내부 요소(키 글자 + 스킬명)를 세로로 쌓는다. align-items: center로 가로 중앙 정렬도 함께 적용한다.

min-width: 90px

스킬명 길이에 따라 버튼 너비가 제각각이 되는 걸 방지한다. 최소 90px을 보장해서 버튼들의 크기가 균일하게 보인다.

hover vs active 차이

hover는 마우스를 올렸을 때(rgba 0.08 — 더 연하게), active는 선택된 상태(rgba 0.12 — 조금 더 진하게). 두 상태를 시각적으로 구분해서 현재 선택된 탭을 명확히 표시한다.

04

스킬 섹션 레이아웃

.skill-wrap {
  display: flex;
  gap: 40px;
  align-items: flex-start;
}

.skill-img {
  width: 280px;
  min-width: 280px;
  border-radius: 8px;
  border: 1px solid #2a2a2a;
  object-fit: cover;
}
display: flex

이미지(왼쪽)와 텍스트(오른쪽)를 가로로 나란히 배치한다. flex가 없으면 블록 요소라 세로로 쌓인다.

align-items: flex-start

기본값(stretch)은 자식 요소를 컨테이너 높이에 맞게 늘린다. flex-start로 바꾸면 각 요소가 자신의 내용 높이만큼만 차지한다. 없으면 이미지가 텍스트 높이에 맞게 늘어난다.

min-width: 280px

flex 컨테이너 안에서는 공간이 부족하면 요소가 줄어들 수 있다. min-width로 이미지가 최소 280px 이하로 줄어들지 않게 고정한다.

object-fit: cover

이미지 비율을 유지하면서 지정한 크기를 꽉 채운다. 이미지가 잘릴 수 있지만 비율이 깨지지 않는다.

05

스킬 텍스트

.skill-text {
  flex: 1;
  display: flex;
  flex-direction: column;
  gap: 24px;
}

.skill-desc p:first-child {
  color: #666;
  font-style: italic;
  font-size: 12px;
  border-left: 2px solid #2a2a2a;
  padding-left: 10px;
}

.skill-desc b {
  color: #c9a84c;
}
flex: 1

flex 아이템이 남은 공간을 전부 차지하게 한다. 이미지가 280px 고정이고, .skill-text는 flex: 1로 나머지 공간을 모두 가져간다.

.skill-desc p:first-child

:first-child는 형제 요소 중 첫 번째인 요소만 선택한다. 나무위키 인용문인 첫 번째 p만 이탤릭 + 왼쪽 보더로 일반 설명과 시각적으로 구분한다.

.skill-desc b { color: #c9a84c }

HTML에서 <b> 태그로 감싼 텍스트를 골드색으로 강조한다. "재사용 대기시간이 초기화 된다" 같은 핵심 내용을 부각시킨다.

06

팁 박스

.tip {
  background: rgba(201,168,76,0.04);
  border: 1px solid #2a2a2a;
  border-left: 3px solid #c9a84c;
  border-radius: 0 8px 8px 0;
  padding: 16px 20px;
}
border vs border-left 중복 선언

border로 4면 모두 얇은 선(1px #2a2a2a)을 먼저 그린 뒤, border-left로 왼쪽만 덮어씌워서 3px 골드 선으로 바꾼다. CSS는 나중에 선언된 속성이 앞 것을 덮어쓰는 원리를 이용한 패턴이다.

border-radius: 0 8px 8px 0

값이 4개면 좌상/우상/우하/좌하 순서다. 왼쪽(0, 0)은 직각, 오른쪽(8px, 8px)만 라운드 처리한다. 왼쪽 골드 보더가 강조선처럼 보이는 인용구 스타일이 된다.

background: rgba(201,168,76,0.04)

골드색(#c9a84c = rgb 201,168,76)을 투명도 4%로 매우 연하게 깔아서 팁 박스 영역을 미묘하게 구분한다. 너무 진하면 배경이 튀어 보인다.

07

콤보 박스

.combo {
  background: #141414;
  border: 1px solid #2a2a2a;
  border-radius: 8px;
  padding: 16px 20px;
}

.combo ul {
  list-style: none;
}

.combo li {
  padding-left: 14px;
  position: relative;
}

.combo li::before {
  content: "▸";
  position: absolute;
  left: 0;
  color: #c9a84c;
}
list-style: none

기본 불릿(•)이나 숫자를 제거한다. 대신 ::before 가상 요소로 커스텀 아이콘(▸)을 직접 만들어 넣는다.

position: relative + absolute 조합

부모(li)에 relative, 자식(::before)에 absolute를 주면 ::before가 li 기준으로 위치를 잡는다. left: 0으로 li 왼쪽 끝에 ▸를 고정하고, li에는 padding-left: 14px을 줘서 텍스트가 ▸와 겹치지 않게 한다.

08

}
border-top: 1px solid #2a2a2a

콤보 목록(ul)과 응용 상세(combo-detail) 사이에 가로 구분선을 넣는다. margin-top과 padding-top으로 위아래 공간도 확보한다.

.combo-item { border-left: 2px solid #c9a84c }

각 응용 콤보 카드에 왼쪽 골드 선을 넣어서 팁 박스와 동일한 인용구 스타일로 통일한다.

.combo-title의 !important들

.skill-desc p:first-child 규칙이 .combo-item 안의 첫 번째 p에도 영향을 미쳐서 이탤릭 + 왼쪽 보더가 붙는 문제가 있었다. !important로 강제로 덮어씌워서 콤보 제목의 스타일을 보호한다.
